# consistency

A year of dots per goal. Each dot is a day. Fill it.

- **Goals:** tabs at the top (`ml  dsa  +`). Tap to switch, swipe left/right, or `←` / `→` / `1–9`.
  Tap the active tab to rename it; clear the name to delete it. `+` adds a goal.
- **Mark today:** tap anywhere, or press `Space`. Marks the goal you're on. (Never unmarks.)
- **Day summary:** tap any dot. You get that day with every goal: tap a goal to mark it
  done or not done, and write what you did. Writing a note marks it done. `‹ ›` steps between days. `n` opens today.
- **Other years:** tap the year.
- **Backup:** `e` exports JSON, `i` imports it.

Light/dark follows your system. Today's dot breathes until you fill it. A streak
doesn't break until a whole day is missed.

No account, no server, no build. Data stays in your browser (`localStorage`).

## Run it

GitHub repo **Settings → Pages** → deploy this branch from `/ (root)`, open the URL on your
phone → **Add to Home Screen**. Works offline.
